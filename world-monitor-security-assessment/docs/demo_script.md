# Demo Script (for judges)

1. **Hook (30s)** — "We didn't just run a scanner and paste the output —
   we built a reusable security assessment tool with AI-assisted triage."
2. **Show the scanner running (1 min)** — live terminal run against the
   local instance, findings.json populating
3. **Dashboard walkthrough (1 min)** — severity heatmap, attack surface map
4. **Chained attack demo (2 min)** — the one narrative PoC: walk through
   XSS → token theft → IDOR → account takeover, with the video/screenshots
5. **AI triage in action (1 min)** — show a raw finding vs. its AI-enriched
   writeup + remediation suggestion
6. **CI integration (30s)** — show the GitHub Action catching a
   reintroduced vulnerability on a PR
7. **Compliance mapping (30s)** — CERT-IN/OWASP scorecard slide
8. **Close** — remediation impact summary + what you'd do with more time
